                           TECHNOLOGY STACK
═══════════════════════════════════════════════════════════════════════════════

Layer 1 - Data Extraction:
  • yt-dlp              → YouTube playlist downloads
  • ffmpeg              → Audio format conversion

Layer 2 - Audio Processing:
  • OpenAI Whisper      → Speech-to-text (local)
  • OpenAI API          → Speech-to-text (cloud)
  • WhisperX            → Enhanced Whisper with diarization
  • pyannote.audio      → Speaker diarization
  • pydub / librosa     → Audio manipulation

Layer 3 - NLP & Analysis:
  • LangChain           → RAG framework
  • OpenAI GPT-4        → LLM for analysis & generation
  • FAISS               → Vector similarity search
  • tiktoken            → Token counting

Layer 4 - Application:
  • Pydantic            → Data validation
  • Click               → CLI framework
  • python-dotenv       → Config management
  • colorlog            → Colored logging

Layer 5 - ML Infrastructure:
  • PyTorch             → Deep learning backend
  • transformers        → HuggingFace models
  • CUDA (optional)     → GPU acceleration

═══════════════════════════════════════════════════════════════════════════════
                              DATA FLOW
═══════════════════════════════════════════════════════════════════════════════

1. INPUT
   YouTube URL → yt-dlp → MP3 files (data/)

2. TRANSCRIPTION
   MP3 → Whisper → Raw segments
   MP3 → pyannote → Speaker timestamps
   Segments + Timestamps → Aligner → Aligned segments
   Aligned → Identifier → HOST/GUEST labels
   Labeled → Cleaner → Clean text
   Clean → JSON (output/transcripts/)

3. ANALYSIS
   Transcript JSON → Text splitter → Chunks
   Chunks → Embeddings → FAISS index
   Query + FAISS → Retrieval → Context
   Context → GPT-4 → Investment thesis
   Thesis → JSON (output/analyses/)

4. MARKETING
   Analysis JSON + Transcript → Prompt templates
   Templates → GPT-4 → LinkedIn post
   Templates → GPT-4 → Carousel slides
   Templates → GPT-4 → Quotes extraction
   All → JSON (output/marketing/)

5. OUTPUT
   JSON files structured for marketing team consumption

═══════════════════════════════════════════════════════════════════════════════
                           KEY ALGORITHMS
═══════════════════════════════════════════════════════════════════════════════

1. IoU-Based Alignment (aligner.py)
   • Calculates Intersection over Union for temporal segments
   • Uses bucketed time index for O(1) lookup
   • Threshold: 0.3 for robust matching

2. Speaker Identification (speaker_identifier.py)
   • Weighted scoring system:
     - Speaking time ratio (weight: 2.0)
     - Question pattern count (weight: 1.0)
     - Turn order (weight: 1.0)
     - Turn frequency (weight: 1.0)
   • Heuristic: Longest speaker = GUEST

3. RAG Pipeline (investment_agent.py)
   • Recursive text splitting (2000 char chunks, 200 overlap)
   • OpenAI embeddings
   • FAISS vector store
   • Top-k retrieval (k=5)
   • Prompt-based analysis with context

4. Marketing Generation (marketing_agent.py)
   • Template-based prompting
   • Tone modulation (technical vs didactic)
   • Structured output parsing
   • Multi-format generation

═══════════════════════════════════════════════════════════════════════════════
                          PERFORMANCE NOTES
═══════════════════════════════════════════════════════════════════════════════

Bottlenecks:
  1. Diarization (pyannote)  → 3-5 min per episode
  2. Transcription (local)   → 2-3 min per episode
  3. Download (YouTube)      → 2-5 min per episode

Optimizations:
  • Use OpenAI API for transcription (1-2 min)
  • Parallel downloads possible
  • Skip stages for reprocessing
  • Batch mode for multiple episodes

Scalability:
  • Linear time complexity per episode
  • Can process playlists of 100+ videos
  • Memory efficient (streaming where possible)
